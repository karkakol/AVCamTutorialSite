## Notes for the author

- In the iOS 27.1 SDK, `AVAssetWriterInput.isReadyForMoreMediaData` and `append(_:)` are deprecated for Swift since iOS 27.0 (`AVAssetWriterInput.h:158-165, 259-265`) in favor of the async append API. With the deployment target 26.0, the compiler shows no warning, so "builds with no warnings" stays true. A later chapter could mention the new API.
- The code comment in `MultiCamCapture.swift` says "A value above 1 means that the device can overheat" for `systemPressureCost`. The header speaks of a session that cannot run sustainably. The comment is in the app, so the page shows it unchanged.
- The Apple sample records one audio track, not two. The pages now say so, but the ch18 list "Ideas for later" still suggests the direction coordinator and the cost checks; it does not suggest two audio tracks, which is correct.
